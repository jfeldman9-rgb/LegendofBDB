# The Legend of Claudia

A high-definition browser adventure. Gather five memory stars in Duskwind Vale, slip past the shadow wisps, and open the gate.

## Play

Open `index.html` in a modern browser, or the GitHub Pages site:

**https://jfeldman9-rgb.github.io/LegendofBDB/**

The title screen is **The Legend of Claudia** with a **START RESCUE** button.

Controls:

- Desktop: WASD to move, mouse or Q/E to turn the camera, Space to dash, M to mute
- Phone: on-screen joystick and Dash button

The game is a single static page at the repository root (Three.js from a CDN). No build step.

## GitHub Pages

Serve from the **default branch `main` / root** (`index.html` + `.nojekyll`).
